# 代码导航

从 Logic 的契约、计算、治理到展示阅读：

| 目录 | 用途 |
| --- | --- |
| `platform/packages/plus-contracts/` | 类型、输入和学习契约 |
| `services/plus-engine/` | 结构化推断与拟合组件 |
| `services/dynamics/` | 小型神经网络、Bayes 观察核与动态规划的机制实现 |
| `platform/packages/plus-runtime/` | 原生对象、运行与治理 |
| `ops/plus-v2/` | 学习、评测和动作的集成工具，包含内部工具，勿直接全部执行 |
| `platform/apps/lwm-demo/` | 演示工作台与接口 |

研究架构不等于所有组件已经集成。设计主线见 [README](../README.md)，实现范围见 [能力边界](CAPABILITIES.md)。
