# 设计与实现边界

项目主线是 Logic 的快学习与慢学习，完整介绍见 [README](../README.md)。

- **快学习目标**：根据新反馈调整当前判断与局部策略，不直接改变稳定规则。
- **慢学习目标**：通过评测和治理，将可迁移的变化纳入版本化 Logic。
- **当前实现**：仓库包含结构化推断、有限范围的参数拟合，以及反馈、评测和模型版本治理组件；这些组件不等于完整的自主规则学习系统。
- **承载底座**：Open Foundry 提供业务对象、关系与动作结构，计算结果不能绕过授权直接改写业务事实。

完整快慢学习闭环、通用规则归纳和降低 FDE 成本仍是研究与验证目标，不是已经达成的效果承诺。
